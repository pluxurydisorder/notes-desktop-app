# Десктопное приложение «Заметки»

Учебное приложение с графическим интерфейсом на Python и Tkinter. Заметки сохраняются между запусками в JSON-файл в пользовательской папке.

## Запуск

Требуется Python 3.10 или новее с установленным Tkinter. В большинстве обычных установок Python дополнительные зависимости не нужны.

```bash
python3 app.py
```

## Возможности первой версии

- создание заметки с названием и текстом;
- сохранение заметок в локальный JSON-файл;
- просмотр и удаление заметки.

Данные по умолчанию находятся в `~/.notes_desktop_app/notes.json` и не смешиваются с исходным кодом.
