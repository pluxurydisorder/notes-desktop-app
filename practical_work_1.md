# Практическая работа № 1

**Тема:** использование Git для хранения кодовой базы десктопного приложения.  
**Вариант:** «Заметки».

## Цель работы

Создать локальный Git-репозиторий, поместить в него исходные файлы десктопного приложения, выполнить индексирование и коммит, внести изменения и повторить сохранение изменённой версии.

## Используемые средства

- Python 3 с библиотекой Tkinter для графического интерфейса;
- Git для контроля версий;
- JSON для локального хранения заметок.

## Ход выполнения

### 1. Установка и проверка Git

Git можно установить с официальной страницы <https://git-scm.com/downloads>. В macOS при наличии Homebrew используется команда `brew install git`; в Debian/Ubuntu — `sudo apt install git`; в Windows можно использовать официальный установщик Git for Windows.

После установки в терминале проверяется версия:

```bash
git --version
```

В среде, где подготавливался проект, команда вернула `git version 2.47.3`.

### 2. Создание локального репозитория

В терминале нужно перейти в каталог проекта и выполнить инициализацию. Для уже подготовленного проекта репозиторий создан в корневом каталоге `notes_desktop_app`.

```bash
cd notes_desktop_app
git init
git status
```

Git создаёт скрытый каталог `.git`, в котором хранит историю изменений и настройки репозитория.

### 3. Создание файлов

В проект включены следующие файлы:

| Файл | Назначение |
|---|---|
| `app.py` | графический интерфейс приложения на Tkinter |
| `notes_storage.py` | чтение, сохранение, обновление и удаление заметок в JSON |
| `README.md` | описание проекта и инструкция запуска |
| `.gitignore` | исключение временных файлов Python и файлов среды разработки |
| `tests/test_notes_storage.py` | автоматические тесты хранилища |
| `practical_work_1.md` | отчёт о выполнении практической работы |

### 4. Внесение информации в файлы

В `app.py` реализован интерфейс с перечнем заметок, полями названия и текста, кнопками создания, сохранения и удаления. Также добавлены поиск по названию и содержимому и горячие клавиши `Ctrl+N` и `Ctrl+S`.

В `notes_storage.py` реализовано сохранение данных в JSON. Файл пользовательских данных по умолчанию создаётся по пути `~/.notes_desktop_app/notes.json`, поэтому заметки сохраняются после закрытия приложения и находятся отдельно от исходного кода.

### 5. Добавление файлов в индекс Git

Чтобы подготовить первую версию проекта к сохранению, файлы добавляются в индекс:

```bash
git add app.py notes_storage.py README.md .gitignore
git status
```

### 6. Первый коммит

Проиндексированные файлы сохраняются в истории репозитория командой:

```bash
git commit -m "Создана первая версия приложения Заметки"
```

В подготовленном репозитории первый коммит имеет идентификатор `0f5d5f8`.

### 7. Изменение файлов и проверка статуса

После первого коммита в приложение добавлены поиск и горячие клавиши, дополнен `README.md`, создан каталог `tests` с тестами и этот отчёт. Перед повторным добавлением изменений выполняется:

```bash
git status --short
```

Непроиндексированные изменения отображаются как изменённые (`M`) или новые (`??`) файлы. Это позволяет увидеть, какие изменения ещё не вошли в следующий коммит.

### 8. Повторное индексирование и второй коммит

Все новые и изменённые файлы добавляются в индекс, после чего выполняется второй коммит:

```bash
git add .
git status
git commit -m "Добавлены поиск, горячие клавиши и тесты"
git log --oneline -2
```

Команда `git log --oneline -2` показывает два последних коммита и подтверждает, что история проекта содержит как первоначальную версию, так и последующие изменения.

## Проверка работоспособности

Тесты слоя хранения запускаются из корневого каталога проекта:

```bash
python3 -m unittest discover -s tests -v
```

Тестами проверяются создание и чтение заметки, обновление без создания дубликата, удаление, отказ от пустого названия и корректная запись кириллицы в UTF-8 JSON.

Для запуска графического приложения используется команда:

```bash
python3 app.py
```

## Вывод

В ходе работы создано десктопное приложение «Заметки» и локальный Git-репозиторий для хранения его кодовой базы. Файлы были добавлены в индекс и сохранены коммитом; затем в код внесены изменения, проверен статус рабочей директории и создан повторный коммит. Таким образом, освоены основные команды жизненного цикла Git: `init`, `status`, `add`, `commit` и `log`.
